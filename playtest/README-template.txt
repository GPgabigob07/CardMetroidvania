CARD METROIDVANIA — PLAYTEST 01

Extract the entire ZIP into a folder before starting CardMetroidvania.exe.
Keep the executable, its _Data folder and DLLs together. Unity is not required.

This is an unfinished exploratory prototype. Progress is not saved: returning
to the title screen or quitting starts a fresh run next time.

Try the tutorial, experiment with movement and melee combat, then follow the
route into the pink area. Spend about 15–20 minutes exploring; there is no
promised ending in this slice. Controls are available from the title and pause
menus. Escape / gamepad Start pauses. Card Time is introduced in the tutorial.

Please send the developer FEEDBACK.txt with your observations and the build ID
from build-info.json. KNOWN_ISSUES.txt describes the limitations of this build.
If something fails, attach Player.log from the log location in build-info.json.
